# 坦克大战 (Tank Battle)

一个使用纯 HTML5 Canvas + JavaScript 实现的经典坦克大战游戏。

## 在线试玩

访问 [https://liang-git1.github.io/tank-battle/](https://liang-git1.github.io/tank-battle/) 即可直接在线游戏（需启用 GitHub Pages）。

或者直接下载 `index.html` 文件，用浏览器打开即可。

## 操作说明

| 操作 | 键盘 | 触屏 |
|------|------|------|
| 移动 | ↑↓←→ 或 WASD | 触摸并滑动 |
| 射击 | 空格键 或 J | 自动射击 |
| 重新开始 | Enter | 点击屏幕 |

## 游戏特性

- 经典坦克大战玩法
- 可破坏砖墙 + 不可破坏钢铁墙
- 敌方 AI 坦克自动寻路和射击
- 计分系统、生命系统、关卡系统
- 道具掉落（生命恢复 ♥ / 速度提升 ⚡）
- 粒子爆炸特效
- 移动端触摸控制支持

## 本地运行

```bash
git clone https://github.com/liang-git1/tank-battle.git
cd tank-battle
# 直接用浏览器打开 index.html
open index.html
```
